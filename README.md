Большинство сетевых конфигураций рассчитано на Cisco Packet Tracer с 2911 и 2960. VPN WireGuard, Wireshark и администрирование Linux/Windows выполняются в среде, явно указанной в соответствующем задании. Команды разных сред не следует смешивать. Каждый стенд независим; одинаковые адреса в разных заданиях не означают одну общую сеть.

Практические инструкции написаны пошагово: список оборудования, подключение каждого кабеля, названия вкладок и полей, устройство для ввода каждой группы команд и проверка результата. Термины поясняются по ходу работы. Для виртуальных машин указаны настройки подключения в VirtualBox; для расчётных заданий объяснено, почему оборудование не требуется.

Если в исходном задании нет адресов, политики доступа или набора событий, приведён конкретный учебный пример с обозначенными допущениями. Значения `<PRIVATE_KEY_A>` и подобные — места для собственных ключей, а не готовые секреты. Результаты проверок в инструкциях — ожидаемые: сетевые стенды и захваты трафика при подготовке материалов не запускались.

Проверены количество и порядок вопросов/билетов, локальные ссылки, создание всех 30 изображений и расчёты подсетей. Рабочие файлы генерации находятся в `.work/`; для чтения решений они не нужны.
