# Сетевое администрирование · практика 5–8

## Задание 5

Соберите простую клиент-серверную сеть и проверьте доступ клиента к серверу по IP-адресу.

### Решение

**Среда:** Cisco Packet Tracer, маршрутизаторы 2911, коммутаторы 2960, PC-PT. Имена портов относятся к этим моделям. Для PC–SW и SW–R используйте Copper Straight-Through, для R–R/SW–SW — Copper Cross-Over или автоматический выбор. Дождитесь зелёных индикаторов. Команды show выполняются из привилегированного режима `#`; на запрос имени при сохранении нажмите Enter.

**Оборудование и схема:** `PC Fa0 — SW1 Fa0/1; Server-PT Fa0 — SW1 Fa0/2`.

На PC откройте **Desktop → IP Configuration → Static**, введите:

| Узел | IPv4 | Маска | Шлюз |
|---|---|---|---|
| PC | 192.168.1.10 | 255.255.255.0 | не нужен |
| Server | 192.168.1.100 | 255.255.255.0 | не нужен |
На Server-PT откройте Services → HTTP → On. На PC выполните `ping 192.168.1.100`, затем Desktop → Web Browser → `http://192.168.1.100`.

**Результат:** ICMP-ответы подтверждают IP-связность, загрузка страницы — доступность HTTP-службы. Если ping проходит, а страница не открывается, проверьте HTTP On и адрес в браузере. Коммутатору для этой работы IP не обязателен.

## Задание 6

Создайте VLAN 10 и VLAN 20, распределите порты коммутатора между VLAN и проверьте сегментацию.

### Решение

**Среда:** Cisco Packet Tracer, маршрутизаторы 2911, коммутаторы 2960, PC-PT. Имена портов относятся к этим моделям. Для PC–SW и SW–R используйте Copper Straight-Through, для R–R/SW–SW — Copper Cross-Over или автоматический выбор. Дождитесь зелёных индикаторов. Команды show выполняются из привилегированного режима `#`; на запрос имени при сохранении нажмите Enter.

**Схема:** PC1/PC2 → SW1 Fa0/1–2 (VLAN10); PC3/PC4 → SW1 Fa0/3–4 (VLAN20).

На PC откройте **Desktop → IP Configuration → Static**, введите:

| Узел | IPv4 | Маска | Шлюз |
|---|---|---|---|
| PC1 | 192.168.10.11 | 255.255.255.0 | не нужен |
| PC2 | 192.168.10.12 | 255.255.255.0 | не нужен |
| PC3 | 192.168.20.11 | 255.255.255.0 | не нужен |
| PC4 | 192.168.20.12 | 255.255.255.0 | не нужен |

**SW1 — CLI:**

```cisco
enable
configure terminal
vlan 10
 name USERS
 exit
vlan 20
 name SERVERS
 exit
interface range fa0/1 - 2
 switchport mode access
 switchport access vlan 10
 spanning-tree portfast
 exit
interface range fa0/3 - 4
 switchport mode access
 switchport access vlan 20
 spanning-tree portfast
 exit
end
copy running-config startup-config
```
**Проверка:** `show vlan brief`. PC1 → `ping 192.168.10.12` проходит, PC3 → `ping 192.168.20.12` проходит, межвлановый ping не проходит. Для дополнительной проверки именно L2-изоляции временно назначьте PC3 192.168.10.13/24: PC1 не должен достигать его, пока порты в разных VLAN; затем верните адрес. Маршрутизатор отсутствует, поэтому межвлановый обмен не настроен.

## Задание 7

Настройте соединение между коммутаторами для передачи трафика нескольких VLAN и проверьте принадлежность портов.

### Решение

**Среда:** Cisco Packet Tracer, маршрутизаторы 2911, коммутаторы 2960, PC-PT. Имена портов относятся к этим моделям. Для PC–SW и SW–R используйте Copper Straight-Through, для R–R/SW–SW — Copper Cross-Over или автоматический выбор. Дождитесь зелёных индикаторов. Команды show выполняются из привилегированного режима `#`; на запрос имени при сохранении нажмите Enter.

**Оборудование:** 2 SW и 4 PC. **Подключение:** SW1 Gi0/1 ↔ SW2 Gi0/1; на каждом SW Fa0/1 — PC VLAN10, Fa0/2 — PC VLAN20.

На PC откройте **Desktop → IP Configuration → Static**, введите:

| Узел | IPv4 | Маска | Шлюз |
|---|---|---|---|
| SW1-PC10 | 192.168.10.11 | 255.255.255.0 | не нужен |
| SW2-PC10 | 192.168.10.12 | 255.255.255.0 | не нужен |
| SW1-PC20 | 192.168.20.11 | 255.255.255.0 | не нужен |
| SW2-PC20 | 192.168.20.12 | 255.255.255.0 | не нужен |

**На обоих SW — CLI:**

```cisco
enable
configure terminal
vlan 10
 exit
vlan 20
 exit
interface fa0/1
 switchport mode access
 switchport access vlan 10
 exit
interface fa0/2
 switchport mode access
 switchport access vlan 20
 exit
interface g0/1
 switchport mode trunk
 switchport trunk allowed vlan 10,20
 no shutdown
end
copy running-config startup-config
```
**Проверка:** `show interfaces trunk`, `show vlan brief`, `show interfaces g0/1 switchport`. PC VLAN10 разных SW пингуют друг друга, аналогично VLAN20. Между VLAN обмена нет. На 2960 не вводится `switchport trunk encapsulation dot1q`: он поддерживает только 802.1Q. Native VLAN по умолчанию одинакова с обеих сторон; пользовательские VLAN 10/20 тегируются.

## Задание 8

Настройте межвлановую маршрутизацию между VLAN 10 и VLAN 20 и подтвердите связность между узлами.

### Решение

**Среда:** Cisco Packet Tracer, маршрутизаторы 2911, коммутаторы 2960, PC-PT. Имена портов относятся к этим моделям. Для PC–SW и SW–R используйте Copper Straight-Through, для R–R/SW–SW — Copper Cross-Over или автоматический выбор. Дождитесь зелёных индикаторов. Команды show выполняются из привилегированного режима `#`; на запрос имени при сохранении нажмите Enter.

**Оборудование:** R1, SW1, PC10, PC20. **Схема:**

```text
PC10 Fa0 — SW1 Fa0/1 (VLAN10)
PC20 Fa0 — SW1 Fa0/3 (VLAN20)
SW1 Gi0/1 — R1 Gi0/0 (trunk VLAN10,20)
```

На PC откройте **Desktop → IP Configuration → Static**, введите:

| Узел | IPv4 | Маска | Шлюз |
|---|---|---|---|
| PC10 | 192.168.10.10 | 255.255.255.0 | 192.168.10.1 |
| PC20 | 192.168.20.10 | 255.255.255.0 | 192.168.20.1 |

**SW1 — CLI:**

```cisco
enable
configure terminal
vlan 10
 name USERS
 exit
vlan 20
 name SERVERS
 exit
interface range fa0/1 - 2
 switchport mode access
 switchport access vlan 10
 spanning-tree portfast
 exit
interface range fa0/3 - 4
 switchport mode access
 switchport access vlan 20
 spanning-tree portfast
 exit
interface g0/1
 switchport mode trunk
 switchport trunk allowed vlan 10,20
 no shutdown
 exit
end
copy running-config startup-config
```

**R1 — CLI:**

```cisco
enable
configure terminal
interface g0/0
 no ip address
 no shutdown
 exit
interface g0/0.10
 encapsulation dot1Q 10
 ip address 192.168.10.1 255.255.255.0
 exit
interface g0/0.20
 encapsulation dot1Q 20
 ip address 192.168.20.1 255.255.255.0
 exit
end
copy running-config startup-config
```
**Проверка:** на SW1 `show interfaces trunk`; на R1 `show ip interface brief`, `show ip route`. С PC10 `ping 192.168.10.1`, `ping 192.168.20.10`; в обратную сторону — `ping 192.168.10.10`. Шлюзами служат подинтерфейсы. Отдельные статические маршруты между непосредственно подключёнными сетями не нужны.

Справка: [Cisco — межвлановая маршрутизация 802.1Q](https://www.cisco.com/c/en/us/td/docs/ios-xml/ios/lanswitch/configuration/xe-16-9/lanswitch-xe-16-9-book/lnsw-conf-vlan-ieee.pdf).
