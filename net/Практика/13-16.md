## Задание 13

Для сети 192.168.10.0/24 выполните деление на четыре равные подсети и укажите адрес сети, диапазон узлов и broadcast каждой подсети.

### Решение

#### Что понадобится

Только лист бумаги или обычный калькулятор. Компьютеры, свитчи, маршрутизаторы и кабели в этом задании **добавлять не нужно**: здесь нужно вычислить адреса.

#### Как читать условие

«Подсеть» — отдельная группа IP-адресов. «Адрес сети» обозначает всю группу, а «broadcast» — адрес отправки всем устройствам этой группы. Эти два адреса обычному компьютеру не назначают. `/26` — короткая запись маски 255.255.255.192.

#### Вычисление и готовый ответ

**Среда:** расчёт IPv4; оборудование не требуется. Четыре подсети означают заимствование 2 бит: /24 + 2 = /26. Маска 255.255.255.192, шаг 256−192=64. В каждой подсети 64 адреса, из них 62 обычных адреса узлов.

| Сеть | Диапазон узлов | Broadcast |
|---|---|---|
| 192.168.10.0/26 | 192.168.10.1–192.168.10.62 | 192.168.10.63 |
| 192.168.10.64/26 | 192.168.10.65–192.168.10.126 | 192.168.10.127 |
| 192.168.10.128/26 | 192.168.10.129–192.168.10.190 | 192.168.10.191 |
| 192.168.10.192/26 | 192.168.10.193–192.168.10.254 | 192.168.10.255 |

**Необязательная проверка, если Python уже установлен:** откройте меню Пуск → напишите `IDLE` → откройте IDLE Python → File → New File. Вставьте код ниже, сохраните файл через File → Save, затем нажмите Run → Run Module (F5). Результат появится в окне Python Shell. Для сдачи этого задания достаточно расчёта и таблицы выше.
```python
import ipaddress
for subnet in ipaddress.ip_network('192.168.10.0/24').subnets(new_prefix=26):
    hosts = list(subnet.hosts())
    print(subnet, subnet.netmask, hosts[0], hosts[-1], subnet.broadcast_address)
```
Подсети не пересекаются и вместе покрывают исходные 256 адресов. Если подключать их к маршрутизатору, каждой нужен собственный L3-интерфейс/VLAN и шлюз из её диапазона.

## Задание 14

Для сети 172.16.20.0/26 определите адрес сети, допустимый диапазон адресов узлов и широковещательный адрес.

### Решение

#### Что понадобится

Только лист бумаги или обычный калькулятор. Компьютеры, свитчи, маршрутизаторы и кабели в этом задании **добавлять не нужно**: здесь нужно вычислить адреса.

#### Как читать условие

«Подсеть» — отдельная группа IP-адресов. «Адрес сети» обозначает всю группу, а «broadcast» — адрес отправки всем устройствам этой группы. Эти два адреса обычному компьютеру не назначают. `/26` — короткая запись маски 255.255.255.192.

#### Вычисление и готовый ответ

**Среда:** расчёт, без оборудования. /26 означает 26 бит сети и 6 бит узла. Маска 255.255.255.192, размер блока 64. Последний октет 0 уже кратен размеру блока, поэтому задан именно адрес сети.

- Сеть: **172.16.20.0/26**.
- Первый узел: **172.16.20.1**.
- Последний узел: **172.16.20.62**.
- Broadcast: **172.16.20.63**.
- Всего адресов: 64, доступно узлам: 62; возможный шлюз: .1.

Необязательная проверка в установленном Python: откройте IDLE → File → New File, вставьте код, сохраните файл и нажмите F5. Если Python не установлен, используйте готовый расчёт выше.
```python
import ipaddress
n = ipaddress.ip_network('172.16.20.0/26')
print(n.network_address, n.netmask, n.broadcast_address, n.num_addresses)
print(list(n.hosts())[0], list(n.hosts())[-1])
```
Адрес .64 относится уже к следующей подсети и не может использоваться узлом этой сети.

## Задание 15

Назначьте IPv6-адреса двум сетевым узлам и маршрутизатору, затем проверьте IPv6-связность.

### Решение

#### Шаг 1. Добавьте оборудование

Откройте Cisco Packet Tracer → **File → New** (Файл → Новый). Внизу слева выбирайте категорию, затем модель и щёлкайте по свободному месту рабочего поля.

- **Компьютеры: 2 шт.** Нажмите **End Devices (Конечные устройства)**, выберите **PC-PT**. Имена в инструкции: **PC1, PC2**.
- **Свитчи: 2 шт.** Нажмите **Network Devices → Switches (Сетевые устройства → Коммутаторы)**, выберите **2960**. Имена в инструкции: **SW1, SW2**.
- **Маршрутизаторы: 1 шт.** Нажмите **Network Devices → Routers (Маршрутизаторы)**, выберите **2911**. Имена в инструкции: **R1**.

Чтобы задать имя, щёлкните по устройству → **Config → Display Name**, введите нужное имя и закройте окно. Название **свитч** и **коммутатор** означает одно и то же устройство: оно соединяет компьютеры. Маршрутизатор соединяет разные сети.

#### Шаг 2. Соедините устройства кабелями

Внизу слева нажмите **Connections** (значок молнии). Для каждой строки ниже заново выберите указанный кабель, затем щёлкните первое устройство и его разъём, после этого — второе устройство и его разъём.

1. Выберите **Copper Straight-Through (прямой медный кабель)**. Нажмите **PC1 → FastEthernet0**, затем **SW1 → FastEthernet0/1**.
2. Выберите **Copper Straight-Through (прямой медный кабель)**. Нажмите **SW1 → GigabitEthernet0/1**, затем **R1 → GigabitEthernet0/0**.
3. Выберите **Copper Straight-Through (прямой медный кабель)**. Нажмите **R1 → GigabitEthernet0/1**, затем **SW2 → GigabitEthernet0/1**.
4. Выберите **Copper Straight-Through (прямой медный кабель)**. Нажмите **SW2 → FastEthernet0/1**, затем **PC2 → FastEthernet0**.

Разъём также называется **портом**. В командах `g0/0` — короткая запись GigabitEthernet0/0, `fa0/1` — FastEthernet0/1. У свитча индикатор может сначала быть оранжевым. Разъёмы маршрутизатора станут зелёными после команды `no shutdown` ниже — до настройки красный индикатор здесь допустим.

#### Шаг 3. Настройте маршрутизатор

#### Как вводить команды на свитче или маршрутизаторе

1. Нажмите **устройство, названное перед блоком команд**.
2. Откройте вкладку **CLI** — это окно для ввода команд.
3. Нажмите Enter. Если появится `Would you like to enter the initial configuration dialog? [yes/no]:`, напишите `no` и нажмите Enter. При сообщении `Press RETURN to get started` ещё раз нажмите Enter. Если ещё идёт загрузка, дождитесь приглашения ввода.
4. Вводите строки блока сверху вниз, нажимая **Enter после каждой**. Копируйте только команды внутри блока. Надписи вида `Router>` или `Router#` устройство выводит само.
5. Команда `enable` открывает расширенный режим, `configure terminal` — настройку, `interface` выбирает разъём, `ip address` задаёт ему адрес, `no shutdown` включает разъём, `exit` возвращает на уровень выше, `end` завершает настройку.
6. Последняя команда `copy running-config startup-config` сохраняет настройки. На вопрос `Destination filename [startup-config]?` нажмите **Enter**, дождитесь `[OK]`.

Если ниже снова открываете то же устройство для исправления, начните с указанного блока. Команды проверки `show ...` вводятся после выхода из настройки командой `end`, когда строка заканчивается `#`; если видите `>`, сначала введите `enable`.

#### Настройте маршрутизатор R1

Нажмите **R1 → CLI**. Выполните следующие команды **на этом устройстве**, по одной строке:


```cisco
enable
configure terminal
ipv6 unicast-routing
interface g0/0
 ipv6 address 2001:DB8:10::1/64
 ipv6 address FE80::1 link-local
 no shutdown
 exit
interface g0/1
 ipv6 address 2001:DB8:20::1/64
 ipv6 address FE80::1 link-local
 no shutdown
end
copy running-config startup-config
```
#### Шаг 4. Настройте компьютеры

1. Нажмите **PC1 → Desktop → IP Configuration**. Найдите раздел **IPv6 Configuration**, выберите **Static**.
2. В поле **IPv6 Address** введите `2001:db8:10::10`, в поле длины префикса — **64**, в **IPv6 Gateway / Default Gateway** этого раздела — `fe80::1`.
3. На **PC2** повторите те же клики, но введите адрес `2001:db8:20::10`. Префикс **64** и шлюз `fe80::1` те же.
4. Закройте окна. IPv4-поля в этой работе не заполняйте. IPv6 — другой формат адреса; `64` обозначает размер сети, это не часть самого адреса. Шлюз `fe80::1` относится только к своему кабельному сегменту, поэтому может повторяться по разные стороны маршрутизатора.

#### Где выполнять проверку

- **На компьютере:** нажмите его значок → **Desktop → Command Prompt** (Командная строка). Введите приведённую ниже команду `ping ...` и нажмите Enter. `Reply from ...` означает, что ответ получен; `Request timed out` — ответа нет. Первый запрос иногда не успевает пройти, поэтому повторите проверку.
- **На маршрутизаторе или свитче:** нажмите устройство → **CLI**. Для команд `show ...` используйте режим `#`, как объяснено выше.
- **Для страницы сайта:** нажмите компьютер → **Desktop → Web Browser**, введите адрес из задания и нажмите **Go**. Адрес сайта не вводят в CLI маршрутизатора.

**Проверка:** на R1 `show ipv6 interface brief`, `show ipv6 route`; на PC1 `ping 2001:db8:20::10`, на PC2 `ping 2001:db8:10::10`. В таблице R1 две непосредственно подключённые /64; динамический протокол здесь не требуется. Не переносите IPv4 broadcast в IPv6 — его нет.

**Сохраните работу:** Packet Tracer → **File → Save As**, выберите папку и имя `Задание-15.pkt`. Это сохраняет всю схему; команды `copy ...` выше сохраняют настройки внутри отдельных устройств.
