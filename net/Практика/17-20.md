# Сетевое администрирование · практика 17–20

## Задание 17

Настройте статическую маршрутизацию в топологии из трёх маршрутизаторов и проверьте таблицы маршрутизации.

### Решение

**Среда:** Cisco Packet Tracer, маршрутизаторы 2911, коммутаторы 2960, PC-PT. Имена портов относятся к этим моделям. Для PC–SW и SW–R используйте Copper Straight-Through, для R–R/SW–SW — Copper Cross-Over или автоматический выбор. Дождитесь зелёных индикаторов. Команды show выполняются из привилегированного режима `#`; на запрос имени при сохранении нажмите Enter.

**Оборудование:** 3 R, 3 SW, 3 PC. **Схема:**

```text
PC1 — SW1 — R1 Gi0/0: 192.168.10.1/24
R1 Gi0/1: 10.0.12.1/30 — R2 Gi0/1: 10.0.12.2/30
PC2 — SW2 — R2 Gi0/0: 192.168.20.1/24
R2 Gi0/2: 10.0.23.1/30 — R3 Gi0/1: 10.0.23.2/30
R3 Gi0/0: 192.168.30.1/24 — SW3 — PC3
На каждом SW: Fa0/1 к PC, Gi0/1 к Gi0/0 маршрутизатора.
```

На PC откройте **Desktop → IP Configuration → Static**, введите:

| Узел | IPv4 | Маска | Шлюз |
|---|---|---|---|
| PC1 | 192.168.10.10 | 255.255.255.0 | 192.168.10.1 |
| PC2 | 192.168.20.10 | 255.255.255.0 | 192.168.20.1 |
| PC3 | 192.168.30.10 | 255.255.255.0 | 192.168.30.1 |

**R1 — CLI:**

```cisco
enable
configure terminal
interface g0/0
 ip address 192.168.10.1 255.255.255.0
 no shutdown
 exit
interface g0/1
 ip address 10.0.12.1 255.255.255.252
 no shutdown
 exit
ip route 192.168.20.0 255.255.255.0 10.0.12.2
ip route 192.168.30.0 255.255.255.0 10.0.12.2
ip route 10.0.23.0 255.255.255.252 10.0.12.2
end
copy running-config startup-config
```

**R2 — CLI:**

```cisco
enable
configure terminal
interface g0/0
 ip address 192.168.20.1 255.255.255.0
 no shutdown
 exit
interface g0/1
 ip address 10.0.12.2 255.255.255.252
 no shutdown
 exit
interface g0/2
 ip address 10.0.23.1 255.255.255.252
 no shutdown
 exit
ip route 192.168.10.0 255.255.255.0 10.0.12.1
ip route 192.168.30.0 255.255.255.0 10.0.23.2
end
copy running-config startup-config
```

**R3 — CLI:**

```cisco
enable
configure terminal
interface g0/0
 ip address 192.168.30.1 255.255.255.0
 no shutdown
 exit
interface g0/1
 ip address 10.0.23.2 255.255.255.252
 no shutdown
 exit
ip route 192.168.10.0 255.255.255.0 10.0.23.1
ip route 192.168.20.0 255.255.255.0 10.0.23.1
ip route 10.0.12.0 255.255.255.252 10.0.23.1
end
copy running-config startup-config
```
**Проверка:** `show ip route static` на каждом R; PC1 → `ping 192.168.20.10`, `ping 192.168.30.10`, `tracert 192.168.30.10`; PC3 → `ping 192.168.10.10`. R2 имеет маршрут в обе крайние LAN. Дополнительные маршруты к транзитным /30 обеспечивают диагностику адресов линков. Если один маршрут удалить, соответствующее направление перестанет работать.

## Задание 18

Настройте OSPF для обмена маршрутами между несколькими сетями и проверьте таблицу маршрутизации.

### Решение

**Среда:** Cisco Packet Tracer, маршрутизаторы 2911, коммутаторы 2960, PC-PT. Имена портов относятся к этим моделям. Для PC–SW и SW–R используйте Copper Straight-Through, для R–R/SW–SW — Copper Cross-Over или автоматический выбор. Дождитесь зелёных индикаторов. Команды show выполняются из привилегированного режима `#`; на запрос имени при сохранении нажмите Enter.

**Оборудование:** 3 R, 3 SW, 3 PC.

**Подключение:**

```text
PC1 — SW1 — R1 Gi0/0: 192.168.10.1/24
R1 Gi0/1: 10.0.12.1/30 — R2 Gi0/1: 10.0.12.2/30
PC2 — SW2 — R2 Gi0/0: 192.168.20.1/24
R2 Gi0/2: 10.0.23.1/30 — R3 Gi0/1: 10.0.23.2/30
R3 Gi0/0: 192.168.30.1/24 — SW3 — PC3
На каждом SW: Fa0/1 к PC, Gi0/1 к Gi0/0 маршрутизатора.
```

На PC откройте **Desktop → IP Configuration → Static**, введите:

| Узел | IPv4 | Маска | Шлюз |
|---|---|---|---|
| PC1 | 192.168.10.10 | 255.255.255.0 | 192.168.10.1 |
| PC2 | 192.168.20.10 | 255.255.255.0 | 192.168.20.1 |
| PC3 | 192.168.30.10 | 255.255.255.0 | 192.168.30.1 |

**R1 — CLI:**

```cisco
enable
configure terminal
interface g0/0
 ip address 192.168.10.1 255.255.255.0
 no shutdown
 exit
interface g0/1
 ip address 10.0.12.1 255.255.255.252
 no shutdown
 exit
router ospf 1
 router-id 1.1.1.1
 network 192.168.10.0 0.0.0.255 area 0
 network 10.0.12.0 0.0.0.3 area 0
 passive-interface g0/0
end
copy running-config startup-config
```

**R2 — CLI:**

```cisco
enable
configure terminal
interface g0/0
 ip address 192.168.20.1 255.255.255.0
 no shutdown
 exit
interface g0/1
 ip address 10.0.12.2 255.255.255.252
 no shutdown
 exit
interface g0/2
 ip address 10.0.23.1 255.255.255.252
 no shutdown
 exit
router ospf 1
 router-id 2.2.2.2
 network 192.168.20.0 0.0.0.255 area 0
 network 10.0.12.0 0.0.0.3 area 0
 network 10.0.23.0 0.0.0.3 area 0
 passive-interface g0/0
end
copy running-config startup-config
```

**R3 — CLI:**

```cisco
enable
configure terminal
interface g0/0
 ip address 192.168.30.1 255.255.255.0
 no shutdown
 exit
interface g0/1
 ip address 10.0.23.2 255.255.255.252
 no shutdown
 exit
router ospf 1
 router-id 3.3.3.3
 network 192.168.30.0 0.0.0.255 area 0
 network 10.0.23.0 0.0.0.3 area 0
 passive-interface g0/0
end
copy running-config startup-config
```

**Проверка таблицы маршрутизации:** На каждом R: `show ip ospf neighbor`, `show ip route ospf`, `show ip protocols`. На R2 должны быть два соседа Full, на R1/R3 — по одному. В таблицах появляются O-маршруты к чужим LAN. С PC1 выполните `ping 192.168.30.10` и `tracert 192.168.30.10`. Успех означает связность через R2. Номер процесса 1 локален, но area и параметры канала должны совпадать. LAN-интерфейсы passive: подсети объявляются, но Hello к рабочим станциям не отправляются. На транзитных интерфейсах passive включать нельзя.

Справка по синтаксису: [Cisco OSPF Configuration Guide](https://www.cisco.com/c/en/us/td/docs/ios-xml/ios/iproute_ospf/configuration/xe-16-12/iro-xe-16-12-book.pdf).

```cisco
enable
configure terminal

 network 10.0.12.0 0.0.0.3 area 0

copy running-config startup-config
```

## Задание 20

Настройте взаимодействие между двумя VLAN через маршрутизатор или устройство третьего уровня и проверьте связность.

### Решение

**Среда:** Cisco Packet Tracer, маршрутизаторы 2911, коммутаторы 2960, PC-PT. Имена портов относятся к этим моделям. Для PC–SW и SW–R используйте Copper Straight-Through, для R–R/SW–SW — Copper Cross-Over или автоматический выбор. Дождитесь зелёных индикаторов. Команды show выполняются из привилегированного режима `#`; на запрос имени при сохранении нажмите Enter.

**Оборудование:** R1, SW1, PC10, PC20. **Схема:**

```text
PC10 Fa0 — SW1 Fa0/1 (VLAN10)
PC20 Fa0 — SW1 Fa0/3 (VLAN20)
SW1 Gi0/1 — R1 Gi0/0 (trunk VLAN10,20)
```

На PC откройте **Desktop → IP Configuration → Static**, введите:

| Узел | IPv4 | Маска | Шлюз |
|---|---|---|---|
| PC10 | 192.168.10.10 | 255.255.255.0 | 192.168.10.1 |
| PC20 | 192.168.20.10 | 255.255.255.0 | 192.168.20.1 |

**SW1 — CLI:**

```cisco
enable
configure terminal
vlan 10
 name USERS
 exit
vlan 20
 name SERVERS
 exit
interface range fa0/1 - 2
 switchport mode access
 switchport access vlan 10
 spanning-tree portfast
 exit
interface range fa0/3 - 4
 switchport mode access
 switchport access vlan 20
 spanning-tree portfast
 exit
interface g0/1
 switchport mode trunk
 switchport trunk allowed vlan 10,20
 no shutdown
 exit
end
copy running-config startup-config
```

**R1 — CLI:**

```cisco
enable
configure terminal
interface g0/0
 no ip address
 no shutdown
 exit
interface g0/0.10
 encapsulation dot1Q 10
 ip address 192.168.10.1 255.255.255.0
 exit
interface g0/0.20
 encapsulation dot1Q 20
 ip address 192.168.20.1 255.255.255.0
 exit
end
copy running-config startup-config
```
**Проверка:** PC10 → `ping 192.168.20.10`, PC20 → `ping 192.168.10.10`. На R1 `show ip route connected`, на SW1 `show interfaces trunk`. Это реализация через маршрутизатор. Альтернатива на L3-коммутаторе — SVI VLAN10/VLAN20 и `ip routing`; она требует иной модели оборудования.

Справка: [Cisco — межвлановая маршрутизация 802.1Q](https://www.cisco.com/c/en/us/td/docs/ios-xml/ios/lanswitch/configuration/xe-16-9/lanswitch-xe-16-9-book/lnsw-conf-vlan-ieee.pdf).
