# Сетевое администрирование · практика 17–20

## Задание 17

Настройте статическую маршрутизацию в топологии из трёх маршрутизаторов и проверьте таблицы маршрутизации.

### Решение

#### Шаг 1. Добавьте оборудование

Откройте Cisco Packet Tracer → **File → New** (Файл → Новый). Внизу слева выбирайте категорию, затем модель и щёлкайте по свободному месту рабочего поля.

- **Компьютеры: 3 шт.** Нажмите **End Devices (Конечные устройства)**, выберите **PC-PT**. Имена в инструкции: **PC1, PC2, PC3**.
- **Свитчи: 3 шт.** Нажмите **Network Devices → Switches (Сетевые устройства → Коммутаторы)**, выберите **2960**. Имена в инструкции: **SW1, SW2, SW3**.
- **Маршрутизаторы: 3 шт.** Нажмите **Network Devices → Routers (Маршрутизаторы)**, выберите **2911**. Имена в инструкции: **R1, R2, R3**.

Чтобы задать имя, щёлкните по устройству → **Config → Display Name**, введите нужное имя и закройте окно. Название **свитч** и **коммутатор** означает одно и то же устройство: оно соединяет компьютеры. Маршрутизатор соединяет разные сети.

#### Шаг 2. Соедините устройства кабелями

Внизу слева нажмите **Connections** (значок молнии). Для каждой строки ниже заново выберите указанный кабель, затем щёлкните первое устройство и его разъём, после этого — второе устройство и его разъём.

1. Выберите **Copper Straight-Through (прямой медный кабель)**. Нажмите **PC1 → FastEthernet0**, затем **SW1 → FastEthernet0/1**.
2. Выберите **Copper Straight-Through (прямой медный кабель)**. Нажмите **PC2 → FastEthernet0**, затем **SW2 → FastEthernet0/1**.
3. Выберите **Copper Straight-Through (прямой медный кабель)**. Нажмите **PC3 → FastEthernet0**, затем **SW3 → FastEthernet0/1**.
4. Выберите **Copper Straight-Through (прямой медный кабель)**. Нажмите **SW1 → GigabitEthernet0/1**, затем **R1 → GigabitEthernet0/0**.
5. Выберите **Copper Straight-Through (прямой медный кабель)**. Нажмите **SW2 → GigabitEthernet0/1**, затем **R2 → GigabitEthernet0/0**.
6. Выберите **Copper Straight-Through (прямой медный кабель)**. Нажмите **SW3 → GigabitEthernet0/1**, затем **R3 → GigabitEthernet0/0**.
7. Выберите **Copper Cross-Over (перекрёстный медный кабель)**. Нажмите **R1 → GigabitEthernet0/1**, затем **R2 → GigabitEthernet0/1**.
8. Выберите **Copper Cross-Over (перекрёстный медный кабель)**. Нажмите **R2 → GigabitEthernet0/2**, затем **R3 → GigabitEthernet0/1**.

Разъём также называется **портом**. В командах `g0/0` — короткая запись GigabitEthernet0/0, `fa0/1` — FastEthernet0/1. У свитча индикатор может сначала быть оранжевым. Разъёмы маршрутизатора станут зелёными после команды `no shutdown` ниже — до настройки красный индикатор здесь допустим.

#### Шаг 3. Укажите адреса устройств

Для **каждого** компьютера или сервера из таблицы:

1. Щёлкните по его значку на схеме.
2. Откройте вкладку **Desktop** (Рабочий стол).
3. Нажмите **IP Configuration** (Настройка IP) и выберите **Static** (Вручную).
4. Перепишите значения **из строки именно этого устройства**: «IPv4» → **IPv4 Address / IP Address**, «Маска» → **Subnet Mask**, «Шлюз» → **Default Gateway**.
5. Если у шлюза написано «не нужен», оставьте поле пустым или 0.0.0.0. Остальные поля без указания не меняйте. Закройте окно — значения сохраняются автоматически.

IP-адрес — номер устройства в сети. Маска показывает границы его сети. Шлюз — адрес маршрутизатора, через который компьютер обращается в другие сети. Запись `/24` в пояснениях означает маску 255.255.255.0, `/30` — 255.255.255.252, `/29` — 255.255.255.248. В поля таблицы вводите обычные адреса и маски, без `/24`.


| Узел | IPv4 | Маска | Шлюз |
|---|---|---|---|
| PC1 | 192.168.10.10 | 255.255.255.0 | 192.168.10.1 |
| PC2 | 192.168.20.10 | 255.255.255.0 | 192.168.20.1 |
| PC3 | 192.168.30.10 | 255.255.255.0 | 192.168.30.1 |

#### Что делают основные команды

`ip route` задаёт путь к другой сети: после команды идут адрес этой сети, её маска и адрес соседнего маршрутизатора, которому передать данные.

#### Как вводить команды на свитче или маршрутизаторе

1. Нажмите **устройство, названное перед блоком команд**.
2. Откройте вкладку **CLI** — это окно для ввода команд.
3. Нажмите Enter. Если появится `Would you like to enter the initial configuration dialog? [yes/no]:`, напишите `no` и нажмите Enter. При сообщении `Press RETURN to get started` ещё раз нажмите Enter. Если ещё идёт загрузка, дождитесь приглашения ввода.
4. Вводите строки блока сверху вниз, нажимая **Enter после каждой**. Копируйте только команды внутри блока. Надписи вида `Router>` или `Router#` устройство выводит само.
5. Команда `enable` открывает расширенный режим, `configure terminal` — настройку, `interface` выбирает разъём, `ip address` задаёт ему адрес, `no shutdown` включает разъём, `exit` возвращает на уровень выше, `end` завершает настройку.
6. Последняя команда `copy running-config startup-config` сохраняет настройки. На вопрос `Destination filename [startup-config]?` нажмите **Enter**, дождитесь `[OK]`.

Если ниже снова открываете то же устройство для исправления, начните с указанного блока. Команды проверки `show ...` вводятся после выхода из настройки командой `end`, когда строка заканчивается `#`; если видите `>`, сначала введите `enable`.

#### Настройте маршрутизатор R1

Нажмите **R1 → CLI**. Выполните следующие команды **на этом устройстве**, по одной строке:


```cisco
enable
configure terminal
interface g0/0
 ip address 192.168.10.1 255.255.255.0
 no shutdown
 exit
interface g0/1
 ip address 10.0.12.1 255.255.255.252
 no shutdown
 exit
ip route 192.168.20.0 255.255.255.0 10.0.12.2
ip route 192.168.30.0 255.255.255.0 10.0.12.2
ip route 10.0.23.0 255.255.255.252 10.0.12.2
end
copy running-config startup-config
```

#### Настройте маршрутизатор R2

Нажмите **R2 → CLI**. Выполните следующие команды **на этом устройстве**, по одной строке:


```cisco
enable
configure terminal
interface g0/0
 ip address 192.168.20.1 255.255.255.0
 no shutdown
 exit
interface g0/1
 ip address 10.0.12.2 255.255.255.252
 no shutdown
 exit
interface g0/2
 ip address 10.0.23.1 255.255.255.252
 no shutdown
 exit
ip route 192.168.10.0 255.255.255.0 10.0.12.1
ip route 192.168.30.0 255.255.255.0 10.0.23.2
end
copy running-config startup-config
```

#### Настройте маршрутизатор R3

Нажмите **R3 → CLI**. Выполните следующие команды **на этом устройстве**, по одной строке:


```cisco
enable
configure terminal
interface g0/0
 ip address 192.168.30.1 255.255.255.0
 no shutdown
 exit
interface g0/1
 ip address 10.0.23.2 255.255.255.252
 no shutdown
 exit
ip route 192.168.10.0 255.255.255.0 10.0.23.1
ip route 192.168.20.0 255.255.255.0 10.0.23.1
ip route 10.0.12.0 255.255.255.252 10.0.23.1
end
copy running-config startup-config
```
#### Где выполнять проверку

- **На компьютере:** нажмите его значок → **Desktop → Command Prompt** (Командная строка). Введите приведённую ниже команду `ping ...` и нажмите Enter. `Reply from ...` означает, что ответ получен; `Request timed out` — ответа нет. Первый запрос иногда не успевает пройти, поэтому повторите проверку.
- **На маршрутизаторе или свитче:** нажмите устройство → **CLI**. Для команд `show ...` используйте режим `#`, как объяснено выше.
- **Для страницы сайта:** нажмите компьютер → **Desktop → Web Browser**, введите адрес из задания и нажмите **Go**. Адрес сайта не вводят в CLI маршрутизатора.

**Проверка:** `show ip route static` на каждом R; PC1 → `ping 192.168.20.10`, `ping 192.168.30.10`, `tracert 192.168.30.10`; PC3 → `ping 192.168.10.10`. R2 имеет маршрут в обе крайние LAN. Дополнительные маршруты к транзитным /30 обеспечивают диагностику адресов линков. Если один маршрут удалить, соответствующее направление перестанет работать.

**Сохраните работу:** Packet Tracer → **File → Save As**, выберите папку и имя `Задание-17.pkt`. Это сохраняет всю схему; команды `copy ...` выше сохраняют настройки внутри отдельных устройств.

**Проверка таблицы маршрутизации:** На каждом R: `show ip ospf neighbor`, `show ip route ospf`, `show ip protocols`. На R2 должны быть два соседа Full, на R1/R3 — по одному. В таблицах появляются O-маршруты к чужим LAN. С PC1 выполните `ping 192.168.30.10` и `tracert 192.168.30.10`. Успех означает связность через R2. Номер процесса 1 локален, но area и параметры канала должны совпадать. Разъёмы к компьютерам отмечены passive: маршрутизатор сообщает о подключённых сетях, но не ищет на этих разъёмах другие маршрутизаторы. На разъёмах между маршрутизаторами этот запрет обмена включать нельзя.

Справка по синтаксису: [Cisco OSPF Configuration Guide](https://www.cisco.com/c/en/us/td/docs/ios-xml/ios/iproute_ospf/configuration/xe-16-12/iro-xe-16-12-book.pdf).
