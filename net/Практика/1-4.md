# Сетевое администрирование · практика 1–4

## Задание 1

В сетевом симуляторе создайте сеть из двух маршрутизаторов и двух локальных сетей. Назначьте IPv4-адреса и проверьте связность.

### Решение

**Среда:** Cisco Packet Tracer, маршрутизаторы 2911, коммутаторы 2960, PC-PT. Имена портов относятся к этим моделям. Для PC–SW и SW–R используйте Copper Straight-Through, для R–R/SW–SW — Copper Cross-Over или автоматический выбор. Дождитесь зелёных индикаторов. Команды show выполняются из привилегированного режима `#`; на запрос имени при сохранении нажмите Enter.

**Оборудование:** 2 R, 2 SW, 2 PC.

**Подключение:**

```text
PC-A Fa0 — SW1 Fa0/1; SW1 Gi0/1 — R1 Gi0/0
R1 Gi0/1 (10.0.12.1/30) — R2 Gi0/1 (10.0.12.2/30)
R2 Gi0/0 — SW2 Gi0/1; SW2 Fa0/1 — PC-B Fa0
```

На PC откройте **Desktop → IP Configuration → Static**, введите:

| Узел | IPv4 | Маска | Шлюз |
|---|---|---|---|
| PC-A | 192.168.10.10 | 255.255.255.0 | 192.168.10.1 |
| PC-B | 192.168.20.10 | 255.255.255.0 | 192.168.20.1 |

**R1 — CLI:**

```cisco
enable
configure terminal
interface g0/0
 ip address 192.168.10.1 255.255.255.0
 no shutdown
 exit
interface g0/1
 ip address 10.0.12.1 255.255.255.252
 no shutdown
 exit
ip route 192.168.20.0 255.255.255.0 10.0.12.2
end
copy running-config startup-config
```

**R2 — CLI:**

```cisco
enable
configure terminal
interface g0/0
 ip address 192.168.20.1 255.255.255.0
 no shutdown
 exit
interface g0/1
 ip address 10.0.12.2 255.255.255.252
 no shutdown
 exit
ip route 192.168.10.0 255.255.255.0 10.0.12.1
end
copy running-config startup-config
```

**Проверка:** На PC-A в Desktop → Command Prompt выполните `ping 192.168.10.1`, затем `ping 192.168.20.10`; на PC-B — `ping 192.168.10.10`. На маршрутизаторах выполните `show ip interface brief` и `show ip route`. Ожидаются up/up и маршруты C/L к локальным сетям, S к удалённой. Первый ping может потерять пакет при ARP; повторите. Если ответов нет, проверьте шлюзы PC, маски, `no shutdown` и обратный маршрут.

## Задание 2

Настройте OSPF между тремя маршрутизаторами и проверьте формирование соседства и появление маршрутов.

### Решение

**Среда:** Cisco Packet Tracer, маршрутизаторы 2911, коммутаторы 2960, PC-PT. Имена портов относятся к этим моделям. Для PC–SW и SW–R используйте Copper Straight-Through, для R–R/SW–SW — Copper Cross-Over или автоматический выбор. Дождитесь зелёных индикаторов. Команды show выполняются из привилегированного режима `#`; на запрос имени при сохранении нажмите Enter.

**Оборудование:** 3 R, 3 SW, 3 PC.

**Подключение:**

```text
PC1 — SW1 — R1 Gi0/0: 192.168.10.1/24
R1 Gi0/1: 10.0.12.1/30 — R2 Gi0/1: 10.0.12.2/30
PC2 — SW2 — R2 Gi0/0: 192.168.20.1/24
R2 Gi0/2: 10.0.23.1/30 — R3 Gi0/1: 10.0.23.2/30
R3 Gi0/0: 192.168.30.1/24 — SW3 — PC3
На каждом SW: Fa0/1 к PC, Gi0/1 к Gi0/0 маршрутизатора.
```

На PC откройте **Desktop → IP Configuration → Static**, введите:

| Узел | IPv4 | Маска | Шлюз |
|---|---|---|---|
| PC1 | 192.168.10.10 | 255.255.255.0 | 192.168.10.1 |
| PC2 | 192.168.20.10 | 255.255.255.0 | 192.168.20.1 |
| PC3 | 192.168.30.10 | 255.255.255.0 | 192.168.30.1 |

**R1 — CLI:**

```cisco
enable
configure terminal
interface g0/0
 ip address 192.168.10.1 255.255.255.0
 no shutdown
 exit
interface g0/1
 ip address 10.0.12.1 255.255.255.252
 no shutdown
 exit
router ospf 1
 router-id 1.1.1.1
 network 192.168.10.0 0.0.0.255 area 0
 network 10.0.12.0 0.0.0.3 area 0
 passive-interface g0/0
end
copy running-config startup-config
```

**R2 — CLI:**

```cisco
enable
configure terminal
interface g0/0
 ip address 192.168.20.1 255.255.255.0
 no shutdown
 exit
interface g0/1
 ip address 10.0.12.2 255.255.255.252
 no shutdown
 exit
interface g0/2
 ip address 10.0.23.1 255.255.255.252
 no shutdown
 exit
router ospf 1
 router-id 2.2.2.2
 network 192.168.20.0 0.0.0.255 area 0
 network 10.0.12.0 0.0.0.3 area 0
 network 10.0.23.0 0.0.0.3 area 0
 passive-interface g0/0
end
copy running-config startup-config
```

**R3 — CLI:**

```cisco
enable
configure terminal
interface g0/0
 ip address 192.168.30.1 255.255.255.0
 no shutdown
 exit
interface g0/1
 ip address 10.0.23.2 255.255.255.252
 no shutdown
 exit
router ospf 1
 router-id 3.3.3.3
 network 192.168.30.0 0.0.0.255 area 0
 network 10.0.23.0 0.0.0.3 area 0
 passive-interface g0/0
end
copy running-config startup-config
```

**Проверка:** На каждом R: `show ip ospf neighbor`, `show ip route ospf`, `show ip protocols`. На R2 должны быть два соседа Full, на R1/R3 — по одному. В таблицах появляются O-маршруты к чужим LAN. С PC1 выполните `ping 192.168.30.10` и `tracert 192.168.30.10`. Успех означает связность через R2. Номер процесса 1 локален, но area и параметры канала должны совпадать.

Справка по синтаксису: [Cisco OSPF Configuration Guide](https://www.cisco.com/c/en/us/td/docs/ios-xml/ios/iproute_ospf/configuration/xe-16-12/iro-xe-16-12-book.pdf).

## Задание 3

Создайте топологию с коммутатором и несколькими узлами, настройте адресацию и подтвердите обмен данными.

### Решение

**Среда:** Cisco Packet Tracer, маршрутизаторы 2911, коммутаторы 2960, PC-PT. Имена портов относятся к этим моделям. Для PC–SW и SW–R используйте Copper Straight-Through, для R–R/SW–SW — Copper Cross-Over или автоматический выбор. Дождитесь зелёных индикаторов. Команды show выполняются из привилегированного режима `#`; на запрос имени при сохранении нажмите Enter.

**Оборудование:** SW1 и 3 PC. Подключите PC1/PC2/PC3 Fa0 к SW1 Fa0/1–3. Все порты оставьте в VLAN 1.

На PC откройте **Desktop → IP Configuration → Static**, введите:

| Узел | IPv4 | Маска | Шлюз |
|---|---|---|---|
| PC1 | 192.168.1.10 | 255.255.255.0 | не нужен |
| PC2 | 192.168.1.20 | 255.255.255.0 | не нужен |
| PC3 | 192.168.1.30 | 255.255.255.0 | не нужен |

**SW1 — CLI:**

```cisco
enable
configure terminal
hostname SW1
interface range fa0/1 - 3
 switchport mode access
 switchport access vlan 1
 spanning-tree portfast
 no shutdown
end
copy running-config startup-config
```

**Проверка:** с PC1 `ping 192.168.1.20` и `ping 192.168.1.30`; на SW1 `show mac address-table` и `show interfaces status`. После обмена должны появиться MAC-адреса PC на правильных портах. Шлюз для обмена в одной /24 не требуется.

## Задание 4

Настройте беспроводную сеть с SSID и защитой WPA2 или WPA3, подключите клиент и проверьте доступность сети.

### Решение

**Среда и устройства:** Packet Tracer, Wireless Router WRT300N и Laptop-PT с Wi-Fi-модулем WPC300N (при замене модуля выключите питание ноутбука). Ещё один PC подключите Fa0 к Ethernet 1 WRT300N прямым кабелем; порт Internet в этой работе не используется.

**Схема:** `Laptop ))) SSID ExamWiFi — WRT300N 192.168.50.1/24 — PC 192.168.50.10/24`.

1. На WRT300N в GUI → Setup задайте Local IP 192.168.50.1, маску 255.255.255.0, DHCP Server Enable, Start IP 192.168.50.100 и 50 клиентов; сохраните.
2. Wireless → Basic Wireless Settings: SSID ExamWiFi. Wireless Security: WPA2-Personal, AES, учебный ключ `Exam-WiFi-2026-Study!`; сохраните. Это пример для стенда, в рабочей сети выбирают собственный секрет.
3. PC назначьте 192.168.50.10/24, шлюз 192.168.50.1. На ноутбуке Desktop → PC Wireless выберите ExamWiFi, введите ключ, затем Desktop → IP Configuration → DHCP.
4. На ноутбуке откройте Command Prompt: `ipconfig`, `ping 192.168.50.1`, `ping 192.168.50.10`.

**Результат:** ноутбук ассоциирован с SSID, получил адрес .100–.149 и достигает проводного PC. WPA3 зависит от оборудования и симулятора; для воспроизводимости выбран разрешённый условием WPA2. Проверка Интернета здесь не нужна.
